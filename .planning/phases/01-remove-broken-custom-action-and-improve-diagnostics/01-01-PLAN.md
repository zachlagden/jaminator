## Phase Goal

**As a** Jam Coding technician, **I want to** install Jaminator by double-clicking the MSI on any classroom laptop, **so that** the install completes without the SFXCA CLR-load failure that rolls back v0.7.4's install path.

<objective>
Surgically remove the `CheckForNewerVersion` custom action from `installer/installer.wxs` — three elements (`<Binary Id="UpdateCheckCA">`, `<CustomAction Id="CheckForNewerVersion">`, and the entire `<InstallUISequence>` block whose sole child is `CheckForNewerVersion`) — while preserving every unrelated element. This is the WiX-source half of INSTALL-03; the build pipeline (Plan 2) and project deletion (Plan 3) follow.

Purpose: Eliminate the WiX-level declaration of the broken managed CA so that subsequent WiX builds emit an MSI without `UpdateCheckCA` in the Binary table, no `CheckForNewerVersion` row in the CustomAction table, and no entry in the InstallUISequence table that references it.

Output: An `installer/installer.wxs` of approximately 169 lines (down from 175) with the three target elements removed, the `<UI><Publish>` ExitDialog block preserved, and ready for a clean commit (`fix(installer): remove CheckForNewerVersion custom action from WiX source` per D-11 commit 1).
</objective>
