Extend `src/Jaminator/Services/ManifestFetcher.FetchAsync` to perform a dual fetch (public manifest + private secrets), join SSID→PSK in memory, cache both files atomically as a pair, and fall back to the joined cache pair when either online fetch fails. - `FetchSecretsWithBearerAsync(string url, string pat, string userAgent)` — per-request `HttpRequestMessage` with Bearer auth, Accept, User-Agent, X-GitHub-Api-Version headers (RESEARCH.md Pattern 4)
- `JoinPsks(Manifest manifest, Dictionary<string, string> secrets)` — fills `WifiProfileEntry.Psk` by SSID lookup; leaves unmatched profiles' `Psk == null`
- `WriteCachedPair(string publicJson, string secretsJson)` — `.NET 4.8`-compatible `File.Delete` + `File.Move` atomic-pair write (RESEARCH.md Pattern 3)

       ```csharp
       private static async Task<string> FetchSecretsWithBearerAsync(string url, string bearerToken, string userAgent)
       {
           using var req = new HttpRequestMessage(HttpMethod.Get, url);
           req.Headers.Authorization = new AuthenticationHeaderValue("Bearer", bearerToken);
           req.Headers.Accept.Add(new MediaTypeWithQualityHeaderValue("application/vnd.github.raw+json"));
           req.Headers.UserAgent.ParseAdd(userAgent);
           req.Headers.Add("X-GitHub-Api-Version", "2026-03-10");

           using var resp = await Http.SendAsync(req).ConfigureAwait(false);
           resp.EnsureSuccessStatusCode();
           return await resp.Content.ReadAsStringAsync().ConfigureAwait(false);
       }
       ```

       ```csharp
       private static void JoinPsks(Manifest manifest, Dictionary<string, string> secrets)
       ```

       **Helper 3 — `WriteCachedPair`** (D-10, RESEARCH.md Pattern 3 lines 348-354; .NET 4.8 quirk per Pitfall 4):
       ```csharp
       private static void WriteCachedPair(string publicJson, string secretsJson)
       {
           var manifestPath = CachePath;
           var secretsPath = SecretsCachePath;
           var manifestTmp = manifestPath + ".tmp";
           var secretsTmp = secretsPath + ".tmp";

           File.WriteAllText(manifestTmp, publicJson);
           File.WriteAllText(secretsTmp, secretsJson);

           // .NET 4.8 lacks the File.Move(src, dest, overwrite: true) overload
           // (added in .NET Core 3.0). Use Delete-then-Move; both are atomic at the
           // OS level on NTFS. The brief between-the-two-Moves window where
           // manifest is new and secrets is old is documented and accepted for
           // v0.8.0 — HARDEN-06 (M3) will revisit with parallel I/O redesign.
           if (File.Exists(manifestPath)) File.Delete(manifestPath);
           File.Move(manifestTmp, manifestPath);
           if (File.Exists(secretsPath)) File.Delete(secretsPath);
           File.Move(secretsTmp, secretsPath);
       }
       ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Fleet laptop process → public GitHub (raw.githubusercontent.com) | Existing boundary; no auth, HTTPS. Public manifest fetch — no change in trust posture. |
